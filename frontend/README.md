# MelodyVerse Frontend

## Description

This is the frontend for the MelodyVerse application. It is built with React and uses the Tailwind CSS for styling.

## Features

- Login
- Signup
- Forgot Password
- Reset Password
- Verify Email

## Getting Started

1. Clone the repository

```bash
git clone https://github.com/rohankbd/auth-app.git
cd frontend
```

2. Install the dependencies

```bash
npm install
```

3. Start the development server

```bash
npm start
```

4. Open the application in your browser

```bash
http://localhost:3000
```
